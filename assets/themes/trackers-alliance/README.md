# Trackers Alliance artwork

Approved faction coin and wallpaper sources are retained as coin.png and wallpaper.png. The packaged coin SWF is used for both character badge and loading indicator. It uses a filtered 192px runtime texture, a three-second tilt and a six-second glint sweep with half the previous peak opacity and shorter travel. The wallpaper SWF is static; it has no added rings or orbiting balls.

Change artwork only through its tracked generator and approved source files. Runtime appearance and compatibility are assessed separately from successful compilation. Earlier animation notes are historical.
