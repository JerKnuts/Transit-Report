# Individual artwork assets

The package retains Jump Gate and Signal Star for badges/indicators and Survey Sweep for backgrounds from this folder. Orbiting Star, Orbital Chart and Grav-jump Tunnel are embedded in the loading UI templates/scripts. Other files here are legacy design sources and are not installer selections. Faction themes live in assets/themes.

Do not add retired designs back to the installer by regenerating all legacy assets. The package script explicitly selects the retained files.
